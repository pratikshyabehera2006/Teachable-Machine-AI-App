# Teachable-Machine-AI-App
# 🤖 Adaptive AI Classifier

## 📌 Project Overview

This project is an AI-powered web application that performs real-time image classification using a webcam. It is built using Google Teachable Machine and TensorFlow.js.

The system can also collect user-provided data, making it adaptable for different machine learning tasks.

---

## 🚀 Features

* 🎥 Real-time webcam-based prediction
* 🧠 AI model trained using Teachable Machine
* ➕ Add custom classes
* 📸 Capture user data
* 🔄 Adaptive learning approach

---

## 🛠️ Technologies Used

* HTML, CSS, JavaScript
* TensorFlow.js
* Teachable Machine
